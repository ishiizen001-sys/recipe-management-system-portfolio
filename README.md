# Recipe Cost Studio — Portfolio Demo

飲食店のレシピ、食材、原価率を一覧で確認するためのフロントエンドデモです。

## 主な機能

- レシピ一覧とカテゴリ絞り込み
- 1食あたり原価・売価・原価率の表示
- 食材構成の可視化
- 原価率が高いメニューの警告
- レスポンシブ表示

## 公開用の安全設計

- 料理名、食材、分量、価格、仕入情報はすべて架空
- 実店舗、実ユーザー、メールアドレス、認証情報を含まない
- API、DB、Azure、環境変数、画像アップロードを使用しない
- 保存・送信機能のないブラウザー内デモ
- Private版のGit履歴を引き継がず、ゼロから作成

## 技術構成

HTML / CSS / Vanilla JavaScript。外部ライブラリ不要で、GitHub Pagesにそのまま配置できます。

## 公開手順

空の `recipe-management-system-portfolio` リポジトリを作成し、このフォルダの中身だけを追加してください。Private版のclone、fork、mirrorは行わないでください。
